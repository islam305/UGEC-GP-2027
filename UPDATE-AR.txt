تحديث إشعارات المنصة

1. افتح Supabase > SQL Editor، والصق محتوى notifications-setup.sql ثم اضغط Run مرة واحدة. لا تحتاج إعادة تشغيل setup.sql القديم.
2. ارفع index.html وapp.js فقط مكان الملفين الحاليين على GitHub واضغط Commit changes.
3. بعد انتهاء النشر حدّث الصفحة بـ Ctrl+F5، ثم اختبر بحساب الطالب.

زر نسخة بيانات المتصفح القديم يظهر للمشرف فقط.
يمكن لكل حساب حذف إشعار واحد أو كل الإشعارات الحالية، وتظل الحالة محفوظة عند الدخول بنفس الحساب من جهاز آخر.
الحذف يخفي الإشعار من الحساب ولا يحذف التاسك أو السيشن أو التسليم الأصلي.
تظهر علامة صفراء عند وجود إشعار غير مقروء، وتختفي بعد فتح الإشعارات بنجاح وحفظ القراءة.
أي تحديث جديد لسجل له إصدار جديد يظهر كإشعار جديد حتى لو حُذف إشعاره السابق.
التحديثات تظهر بعد تحديث البيانات أو التحديث الدوري الحالي كل دقيقة خارج النوافذ المنبثقة.
تعمل الميزة لكل حساب دخول؛ مستخدمو نفس حساب الفريق يشتركون في حالة القراءة والحذف.
تتضمن النسخة أيضًا الإحصائيات التلقائية السابقة.

اختبارات JavaScript ومحاكاة القراءة والحذف وعزل الحسابات نجحت محليًا. يلزم اختبار SQL والصلاحيات على مشروعك الفعلي بعد تنفيذ الملف.
